# Bug Fix: 首页系统原理图热泵机组数据全部为 0

## 问题分析

### 数据流梳理

首页系统原理图显示热泵状态（运行台数/待机台数/化霜台数/故障台数）的数据来源：

**标准款（standard）当前逻辑：**
```
HomePage.jsx
  └─ useHomeOverviewQuery → getHomeOverview() → 后端 queryHomePageDataNew API
       └─ adaptHomeOverview → extractHomeOverviewSource → adaptNewApiResponse
            └─ 从 API 返回值中取 onlineHeatPump / offlineHeatPump / defrostHeatPump / alarmHeatPump
```

**问题根因：** 标准款首页**只依赖后端 API** (`queryHomePageDataNew`) 返回的聚合数据。如果后端未正确返回这 4 个字段值，前端 adapter 会将它们默认为 0。

前端其实已经有一套**直接轮询 PLC 点位**的完整机制（`useHomeUnitStatusPoll`），但**仅对大剧院 profile 启用**：

```jsx
// HomePage.jsx:150-152
const homeUnitStatusPoll = useHomeUnitStatusPoll({
  enabled: isHomeRoute && isHomeDashboard && isDajuyuanProfile,  // ← 标准款被排除！
})
```

```jsx
// HomePage.jsx:206-208
const heatPumpOverlaySummary = isDajuyuanProfile
  ? homeUnitStatusPoll.heatPump.summary        // 大剧院：用轮询 PLC 数据
  : homeOverview.system.heatPumpSummary         // 标准款：用后端 API 聚合数据
```

`useHomeUnitStatusPoll` 内部已经能：
1. 从 `Sys\FinforWorx\HPTotalNumber` 读取实际热泵台数（15）
2. 逐台读取 `HeatPump\SJMG\No{1..15}\Machine_Operation` 等 4 个点位
3. 聚合为 running / shutdown / defrosting / malfunction 计数

**所以根本原因是：标准款没有启用 PLC 轮询，全靠后端 API，后端未返回正确值导致全 0。**

## 修复方案

让标准款首页也使用 `useHomeUnitStatusPoll` 获取热泵状态数据（与大剧院共用同一套 PLC 轮询逻辑）。

### 修改文件

**`src/pages/HomePage.jsx`**（核心修改）

1. **启用轮询**（移除 `isDajuyuanProfile` 条件）：
```diff
  const homeUnitStatusPoll = useHomeUnitStatusPoll({
-   enabled: isHomeRoute && isHomeDashboard && isDajuyuanProfile,
+   enabled: isHomeRoute && isHomeDashboard,
  })
```

2. **统一使用轮询数据作为原理图热泵状态源**（标准款也用轮询数据而非 API 聚合）：
```diff
  const heatPumpOverlaySummary = isDajuyuanProfile
    ? homeUnitStatusPoll.heatPump.summary
-   : homeOverview.system.heatPumpSummary
+   : homeUnitStatusPoll.heatPump.summary
```

3. **同步修改侧边栏设备状态面板的热泵柱状图数据源**：
```diff
  const deviceStatusHeatPumpData = isDajuyuanProfile
    ? homeUnitStatusPoll.heatPump.chartData
-   : homeOverview.deviceStatus.heatPumpData
+   : homeUnitStatusPoll.heatPump.chartData
```

## 验证方式

1. 启动项目，打开首页
2. 打开浏览器开发者工具 → Console，检查是否有 PLC 点位查询日志
3. 确认系统原理图上的热泵机组区域显示正确的运行/待机/化霜/故障台数（总和应为 15）
4. 确认右侧设备状态面板的热泵柱状图数据也正确
5. 确认大剧院 profile 的行为不受影响（如可切换测试）
