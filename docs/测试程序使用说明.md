# CAS 测试程序使用说明

> 适用于没接触过测试的同学快速上手。

## 一、已安装的内容

| 工具 | 作用 |
| --- | --- |
| **Vitest** | 跑单元测试 / 组件测试 / 集成测试 |
| **@testing-library/react** | 像用户一样操作 React 组件 |
| **Playwright** | 跑端到端（E2E）测试，自动打开浏览器点页面 |
| **jsdom** | 在 Node 里模拟浏览器环境 |

## 二、常用命令

```bash
# 1. 跑所有单元/组件测试
npm run test:unit

# 2. 监听模式开发测试（改代码自动重跑）
npm run test:unit:watch

# 3. 跑所有 E2E 测试（会自动启动 dev server）
npm run test:e2e

# 4. 打开 Playwright 可视化界面调试用
npm run test:e2e:ui

# 5. 查看 E2E 测试报告
npm run test:e2e:report
```

## 四、怎么新增一个单元测试

参考 `src/features/auth/userRole.test.js`：

```js
import { describe, expect, it } from 'vitest'
import { yourFunction } from './yourModule'

describe('yourModule', () => {
  it('描述你要验证的行为', () => {
    expect(yourFunction('input')).toBe('expected')
  })
})
```

## 五、怎么新增一个组件测试

参考 `src/components/ToggleSwitch.test.jsx`：

```js
import { fireEvent, render, screen } from '@testing-library/react'
import { describe, expect, it, vi } from 'vitest'
import YourComponent from './YourComponent'

describe('YourComponent', () => {
  it('点击后触发回调', () => {
    const handleClick = vi.fn()
    render(<YourComponent onClick={handleClick} />)

    fireEvent.click(screen.getByRole('button'))

    expect(handleClick).toHaveBeenCalled()
  })
})
```

如果组件用到了路由或 React Query，用 `renderWithProviders`：

```js
import { renderWithProviders } from '../test/utils'

renderWithProviders(<YourPage />, { route: '/settings/mode-select' })
```

## 六、怎么新增一个 E2E 测试

参考 `tests/e2e/mode-select.spec.js`：

```js
import { test, expect } from '@playwright/test'
import { mockAlgorithmProcess, MOCK_API_HANDLERS } from './helpers/mockApi'

test.describe('你要测的页面', () => {
  test.beforeEach(async ({ page }) => {
    await mockAlgorithmProcess(page, MOCK_API_HANDLERS)
  })

  test('页面能打开', async ({ page }) => {
    await page.goto('/your-path')
    await expect(page.getByText('你要看的文字')).toBeVisible()
  })
})
```

> 提示：`VITE_SKIP_INIT_GATE=true` 已配置在 `playwright.config.js` 的 `webServer.env` 中，E2E 启动时会跳过后端 init 门禁，方便无后端环境跑通。

## 七、遇到接口报错怎么办

- 单元测试里用 `vi.mock('../api/modules/xxx', ...)` 模拟 API。
- E2E 里用 `tests/e2e/helpers/mockApi.js` 统一拦截算法过程接口，按 `algorithmProcessId` 返回 mock 数据。
